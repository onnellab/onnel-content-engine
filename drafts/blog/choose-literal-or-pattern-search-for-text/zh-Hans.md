# 文本搜索该选字面搜索还是模式搜索

搜索带有句点的标记，却找到了意料之外的段落，可能是因为输入的符号被当成规则，而不是文字本身。先确认搜索方式，再考虑把表达式写得更复杂。

## 问题

什么时候应该按原样搜索文字，什么时候应该使用模式？

## 简短回答

查找已知字符串时，先用字面搜索。只有需要用一条规则查找多种形式时，才在核对应用语法后使用模式搜索。先用虚构文本测试应匹配和不应匹配的情况，再在实际文档中只查找、不替换。

## 搜索词的两种含义

字面搜索查找输入的字符，不把它们解释成模式运算符。模式搜索则把某些字符解释成规则。正则表达式是一种模式，但不一定与文件名通配符使用同一套语法。

按原样查找不等于整行匹配、全字匹配、区分大小写或文件字节完全相同。这些是不同的问题。在长句中找到一部分，也可能是字面匹配。

| 任务 | 建议起点 | 信任结果前检查 |
| --- | --- | --- |
| 查找写成 `A.7` 的标记 | 字面搜索 | 标点和大小写选项 |
| 查找明确规定的多种形式 | 支持的模式搜索 | 语法与误匹配 |
| 限定要搜索的文件 | 文件范围设置 | 区分路径过滤与正文搜索 |

## 用虚构的小样本测试

新建一份可丢弃的本地笔记，写入以下三行，不要使用私人信息或真实文档内容。

```text
A.7
Ax7
A-7
```

如果任务是“查找 `A.7` 这个标记”，预期只有第一行。先用字面搜索，检查高亮的字符，不要只看结果数量。

在 [RE2 语法](https://github.com/google/re2/wiki/Syntax)中，句点是通配符，转义后的句点表示符号本身。因此，这个例子里的模式 `A.7` 与 `A\.7` 意图不同。这不是对所用阅读器支持这两个表达式的保证。在字面搜索中，除非要查找反斜杠本身，否则不要直接把它加进去。

通过这个小测试，并不代表规则适合整份文档。例如，`ZA.70` 中的那一部分是否也算结果，需要另外决定。如果相关，就把它加入测试。

## 推荐步骤

1. **用普通语言写清目标。** 要找一个已知短语，还是多种形式？各写一个想要的结果和一个相似但不想要的结果。
2. **保留原文。** 使用只读视图或单独的工作副本。测试文本和观察记录另存，不要把非公开内容上传到在线模式测试网站。
3. **检查实际输入框。** 阅读应用帮助，核对所选方式、转义规则和支持的语法。[Google 帮助](https://support.google.com/docs/answer/62754?hl=en)说明了该产品的正则表达式选项和反斜杠用法，不能视为所有应用的通则。
4. **只查找，不替换。** 在虚构样本中核对每个应匹配和应排除的情况。一次只改一个选项。不清楚原因时，回到较短、辨识度较高的字面搜索。
5. **核对并记录范围。** 确认文件、版本、选区与过滤条件。阅读前后文，在原文之外记录搜索词、模式和相关选项。

## 范围也会改变结果

[VS Code 文档](https://code.visualstudio.com/docs/editing/codebasics)区分正文搜索选项与文件包含、排除用的 glob 模式。不要混用这些输入框。

零结果可能意味着文本不存在，也可能是选区、过滤条件或搜索词有误。先搜索一处确定存在的短语。如果仍找不到，应先排查范围和字符差异，而不是不断扩大模式。检查相似的标点和意外空格，但不要为了方便搜索就批量规范化原文。

## 结论

选择能够表达目标的最简单方式。找到结果，意味着在理解限制的前提下定位到相关文字；它既不能证明已经找全，也不能作为替换的依据。

## 常见问题

### 字面搜索需要给搜索词加引号吗？

只有应用帮助要求时才这样做。否则，引号可能也会成为要查找的文字。

### 有高级搜索就支持正则表达式吗？

不一定。请查阅该输入框的说明。从别处复制的模式可能不受支持，也可能有不同含义。

### 测试通过后可以全部替换吗？

仅凭这一点不够。替换是单独的编辑任务，需要可用备份、实际匹配项复核以及修改后的验证计划。本流程止于查找和记录。
