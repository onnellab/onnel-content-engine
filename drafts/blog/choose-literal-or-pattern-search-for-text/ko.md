# 텍스트 검색에서 일반 검색과 패턴 검색 고르기

점이 포함된 표기를 검색했는데 다른 문장이 나올 수 있습니다. 입력한 기호가 문자 자체가 아니라 검색 규칙으로 해석되었을 수 있기 때문입니다. 검색식을 복잡하게 만들기 전에 현재 검색 방식을 확인하세요.

## 질문

텍스트를 문자 그대로 검색할 때와 패턴으로 검색할 때는 어떻게 구분하나요?

## 짧은 답변

이미 아는 문자열은 문자 그대로 찾는 일반 검색부터 사용하세요. 여러 형태를 하나의 규칙으로 찾을 때만 앱의 문법을 확인한 뒤 패턴 검색을 사용하세요. 가상 텍스트로 일치와 불일치를 시험하고, 실제 문서에서는 바꾸기 없이 결과를 확인하세요.

## 검색어의 두 가지 의미

일반 검색은 입력한 문자를 패턴 연산자로 해석하지 않고 찾는 방식입니다. 패턴 검색은 일부 문자를 규칙으로 해석합니다. 정규식은 패턴의 한 종류이며, 파일명 와일드카드와 반드시 같은 문법을 쓰지는 않습니다.

문자 그대로 찾는다는 말이 줄 전체 일치, 단어 전체 일치, 대소문자 구분이나 파일 바이트의 동일성을 뜻하지는 않습니다. 긴 문장 안의 일부만 일치해도 일반 검색 결과일 수 있습니다.

| 할 일 | 먼저 선택할 방식 | 결과를 믿기 전에 확인할 것 |
| --- | --- | --- |
| `A.7`이라는 표기 찾기 | 일반 검색 | 문장부호와 대소문자 옵션 |
| 정해진 여러 형태 찾기 | 지원되는 패턴 검색 | 문법과 원치 않는 일치 |
| 검색할 파일 제한하기 | 파일 범위 설정 | 경로 필터와 본문 검색어의 구분 |

## 작은 가상 예제로 확인하기

개인정보나 실제 문서 내용을 넣지 않은 임시 로컬 메모에 다음 세 줄을 적으세요.

```text
A.7
Ax7
A-7
```

목표가 “`A.7`이라는 표기 찾기”라면 첫 줄만 원한 결과입니다. 일반 검색부터 시작하고, 결과 개수뿐 아니라 실제 강조된 문자를 확인하세요.

[RE2 문법](https://github.com/google/re2/wiki/Syntax)에서 점은 와일드카드이고, 이스케이프한 점은 점 자체를 뜻합니다. 따라서 이 예제의 패턴 `A.7`과 `A\.7`은 의도가 다릅니다. 사용 중인 리더가 이 식을 지원한다는 뜻은 아닙니다. 일반 검색에서는 역슬래시 자체를 찾으려는 경우가 아니라면 그대로 덧붙이지 마세요.

이 작은 시험을 통과해도 실제 문서의 모든 조건을 다룬 것은 아닙니다. 예를 들어 `ZA.70` 안에 포함된 표기도 결과에 넣을지 따로 결정하세요. 중요하다면 그 사례를 시험 메모에 추가하세요.

## 권장 작업 순서

1. **목표를 말로 적으세요.** 특정 문구 하나가 필요한지, 여러 형태가 필요한지 정하세요. 원하는 결과와 비슷하지만 제외할 결과를 하나씩 적으세요.
2. **원본을 보존하세요.** 읽기 전용 보기나 별도 작업본을 사용하세요. 시험 텍스트와 관찰 기록은 따로 두고, 비공개 내용을 온라인 정규식 시험 사이트에 올리지 마세요.
3. **실제 검색 입력란을 확인하세요.** 선택한 방식의 문법과 이스케이프 규칙을 앱 도움말에서 읽으세요. [Google 도움말](https://support.google.com/docs/answer/62754?hl=en)은 해당 제품의 정규식 옵션과 역슬래시 처리를 설명합니다. 모든 앱의 공통 규칙은 아닙니다.
4. **바꾸기 없이 시험하세요.** 가상 예제에서 일치해야 할 것과 제외할 것을 모두 확인하세요. 옵션은 하나씩 바꾸세요. 동작이 불명확하면 짧고 특징적인 문구의 일반 검색으로 돌아가세요.
5. **범위를 확인하고 기록하세요.** 파일, 버전, 선택 영역과 필터를 확인하세요. 앞뒤 문맥을 읽고 검색어, 방식, 관련 옵션을 원본 밖에 기록하세요.

## 범위가 달라지면 결과도 달라집니다

[VS Code 문서](https://code.visualstudio.com/docs/editing/codebasics)는 본문 검색 옵션과 파일 포함·제외용 glob 패턴을 구분합니다. 두 입력란을 혼동하지 마세요.

결과가 없다고 본문에도 반드시 없는 것은 아닙니다. 선택 영역, 필터나 검색어가 틀릴 수 있습니다. 확실히 존재하는 문구를 먼저 찾아보세요. 그것도 나오지 않으면 패턴을 넓히기 전에 범위와 문자 차이를 확인하세요. 비슷해 보이는 문장부호나 예상하지 못한 공백도 살펴보되, 검색을 맞추려고 원본을 일괄 정리하지 마세요.

## 결론

목표를 표현하는 가장 단순한 방식을 선택하세요. 검색 성공은 한계를 이해한 상태에서 필요한 텍스트를 찾았다는 뜻입니다. 관련된 모든 부분을 찾았거나 바꾸기까지 해도 된다는 뜻은 아닙니다.

## 자주 묻는 질문

### 문자 그대로 찾으려면 따옴표를 붙여야 하나요?

앱 도움말에서 그렇게 안내할 때만 사용하세요. 그렇지 않으면 따옴표도 검색할 문자에 포함될 수 있습니다.

### 고급 검색 버튼이 있으면 정규식을 지원하나요?

반드시 그렇지는 않습니다. 해당 입력란의 설명을 확인하세요. 다른 도구에서 가져온 식은 지원되지 않거나 다르게 해석될 수 있습니다.

### 시험에 성공하면 모두 바꾸기를 해도 되나요?

그것만으로는 부족합니다. 바꾸기는 복구 가능한 백업, 실제 일치 항목 검토와 변경 확인 계획이 필요한 별도 편집 작업입니다. 이 절차는 검색과 기록에서 끝납니다.
