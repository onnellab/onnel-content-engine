영상 업로드 · 채널 조회

연결 테스트는 채널만 조회해요. 시험 영상을 업로드하거나 공개하지 않아요.

1. 최초 한 번만 준비해요

  1. Google Cloud에서 YouTube Data API v3를 켜요.
  2. Google Auth Platform에서 동의 화면과 사용자를 설정해요.
  3. OAuth 클라이언트를 '데스크톱 앱'으로 만들고 JSON을 받아요.
  4. ONNELLAB 채널로 전환한 뒤 고급 설정의 채널 ID를 복사해요.
Google 로그인과 최초 권한 동의는 직접 한 번 진행해야 해요. 다른 채널을 선택하면 저장하지 않아요.

2. ONNELLAB 채널을 연결해요

이 로컬 화면에서만 읽고 Keychain에 저장해요. 공개 대시보드나 GitHub로 보내지 않아요.

이름이나 @handle이 아닌 UC로 시작하는 24자리 채널 ID예요.

재연결에 실패해도 기존 인증은 지우거나 바꾸지 않아요.

자동 공개 전에 확인해요

인증 성공과 공개 업로드 가능 여부는 달라요. 새 API 프로젝트는 Google 검토 전 비공개 업로드로 제한될 수 있어요. Testing 모드에서는 갱신 토큰이 일찍 만료될 수 있어요.

예약 실행 시 이 Mac이 켜져 있고 Keychain에 접근할 수 있어야 해요. 잠금·권한 오류는 무인 실행에서 비밀번호를 묻지 않고 차단해요.
