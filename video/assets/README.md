# Local input assets

This directory intentionally contains no media. Its contents except this README
are ignored. Store only reviewed app recordings and optional narration here, or
choose a private external `--asset-root`. Remove notifications, account details,
filenames revealing personal information, and other private content before use.
No sample is automatically enqueued. Never use synthetic test media as app evidence.
See [the pipeline guide](../../docs/Short_Video_Pipeline.md).
