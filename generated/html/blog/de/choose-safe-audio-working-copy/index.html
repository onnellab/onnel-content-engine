Vor der Audiobearbeitung eine Arbeitskopie anlegen

Ähnliche Dateinamen führen leicht zu Verwechslungen. Bevor Sie ein Interview kürzen oder Aufnahmen zusammenfügen, legen Sie fest, welche Datei unverändert bleiben soll und welche Sie bearbeiten möchten.

Frage

Wie wähle ich vor der Audiobearbeitung eine geeignete Arbeitskopie?

Kurze Antwort

Identifizieren und behalten Sie das Original. Erstellen Sie eine separate, eindeutig benannte Kopie und prüfen Sie, ob Sie genau diese öffnen. Speichern Sie das Ergebnis als neue Datei und hören Sie es vor dem Löschen an. Zwei Dateien auf demselben Gerät sind keine unabhängige Sicherung.

Was ist eine Arbeitskopie?

Eine Audio-Arbeitskopie ist eine eigene Datei für die Bearbeitung, während das Original erhalten bleibt. Das bloße Umbenennen des Originals oder eine Verknüpfung darauf genügt nicht. Eine Sicherung dient dagegen der Wiederherstellung nach einem Verlust. Fällt das Gerät aus, können Original und Kopie auf diesem Gerät gemeinsam verloren gehen.

Praktisches Vorgehen

  1. Original bestimmen. Notieren Sie Speicherort, Namen, Größe und Dauer. Hören Sie eine erkennbare Passage an. Diese Merkmale helfen bei der Zuordnung, beweisen bei Übereinstimmung aber noch keine identischen Inhalte.
  2. Separate Kopie erstellen. Verwenden Sie im Dateimanager „Kopieren“ oder „Duplizieren“, nicht nur „Umbenennen“. Ein Name wie `interview_work_01.wav` kennzeichnet die Arbeitsdatei. Bewahren Sie das Original an einem eindeutig zugeordneten Ort auf und überschreiben Sie es nicht.
  3. Eingabe prüfen. Kontrollieren Sie beim Öffnen Namen und Speicherort. Hören Sie bei ähnlichen Dateien vor dem Bearbeiten nochmals hinein. Ein Eintrag unter zuletzt verwendeten Dateien bestätigt nicht die Identität.
  4. Neues Ergebnis speichern. Wählen Sie etwa `interview_trim_01.wav`. Halten Sie bei einer Rückfrage zum Ersetzen einer Datei an und prüfen Sie zuerst das Ziel. Das Ändern der Dateiendung konvertiert kein Audioformat.
  5. Erneut öffnen und anhören. Prüfen Sie Anfang, Schnittpunkte, Ende und erwartete Dauer. Eine Erfolgsmeldung belegt nicht, dass alle gewünschten Inhalte vorhanden sind. Behalten Sie das Original, bis Ergebnis und erforderliche Sicherung geprüft sind.

Grenzen und optionale Werkzeuge

Eine Arbeitskopie vermindert Verwechslungen, garantiert aber weder Wiederherstellung noch Klangqualität oder Bearbeitungs- und Nutzungsrechte. Wichtige Originale benötigen eine geeignete, separat überprüfte Sicherung. Beginnen Sie weitere Bearbeitungsschritte möglichst beim erhaltenen Ausgangsmaterial, statt bereits komprimierte Ergebnisse wiederholt zu exportieren.

Fazit

Trennen Sie bekanntes Original, Arbeitskopie und Ergebnis. Hören Sie die gespeicherte Datei an, bevor Sie die Aufgabe als erledigt ansehen.

Häufige Fragen

Genügt es, das Original umzubenennen?

Nein. Ein anderer Name erzeugt keine zusätzliche Datei.

Ist die Arbeitskopie zugleich eine Sicherung?

Nicht unbedingt. Dateien auf demselben Gerät teilen Ausfallrisiken. Prüfen Sie bei wichtigen Aufnahmen eine separate Sicherung.

Darf ich das Original nach dem Export löschen?

Entscheiden Sie nicht allein anhand der Erfolgsmeldung. Prüfen Sie das Ergebnis und berücksichtigen Sie spätere Bearbeitungen und Wiederherstellung.
