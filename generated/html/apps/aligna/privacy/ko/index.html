최종 업데이트: 2026-07-30

개인정보 처리방침

Aligna는 사용자의 개인정보를 중요하게 생각하며 아래와 같은 방식으로 운영됩니다.

1. 계정 및 개인 식별 정보

Aligna는 이름, 이메일 주소 또는 전화번호로 가입하거나 로그인하도록 요구하지 않습니다. 아래에 별도로 명시한 선택형 서버 기능을 제외하면 앱 콘텐츠와 사용 기록은 ONNELLAB로 전송되지 않습니다.

2. 앱이 접근하거나 기기에 저장하는 데이터

  • 사용자가 명시적으로 선택한 파일과 파일 메타데이터
  • 기기에 저장되는 이름 변경 규칙, 미리보기, 앱 설정과 구매 권한 정보
  • 미리보기와 이름 변경 작업은 기기에서 이루어집니다.
  • 선택한 파일은 ONNELLAB 서버로 업로드되지 않습니다.
  • iOS에서는 원본 파일을 직접 변경하는 대신 새 이름의 복사본으로 저장될 수 있습니다.

3. 서버 전송

위에 명시한 앱 기능은 ONNELLAB 서버로 파일 내용이나 사용 기록을 전송하지 않습니다.

4. 결제 정보

앱 내 구매는 Apple App Store 또는 Google Play가 처리합니다. Aligna와 ONNELLAB은 카드번호나 은행계좌 정보에 접근하거나 저장하지 않습니다. 스토어가 제공하는 상품·거래·구매 권한 정보는 구매 확인 및 복원에 사용될 수 있습니다.

5. 광고, 분석 및 제3자 제공

Aligna는 광고 SDK, 사용자 행동 분석 SDK 또는 제3자 추적 도구를 사용하지 않습니다. 데이터는 위에 설명한 기능 제공 목적 외에는 판매하지 않으며, 사용자가 운영체제 공유 기능이나 다른 앱을 통해 직접 전달한 경우는 해당 서비스의 처리방침이 적용됩니다.

6. 보관 및 삭제

앱이 관리하는 로컬 데이터는 해당 기능의 삭제 동작 또는 앱 삭제를 통해 기기에서 제거할 수 있습니다. 사용자가 관리하는 원본 및 결과 파일은 사용자가 직접 보관하거나 삭제합니다. ONNELLAB 서버에는 보관되는 앱 콘텐츠가 없습니다.

7. 보안 및 아동의 개인정보

ONNELLAB은 전송이 필요한 데이터에 합리적인 기술적·관리적 보호조치를 적용합니다. Aligna는 만 13세 미만 아동을 대상으로 설계되지 않았으며 아동의 개인정보를 고의로 수집하지 않습니다.

8. 변경 및 문의

앱 기능이나 법적·스토어 요구사항이 변경되면 이 문서를 수정하고 최종 업데이트일을 변경합니다.
