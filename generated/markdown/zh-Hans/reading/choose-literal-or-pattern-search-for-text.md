# 文档里按原文查找，还是按模式查找？

## 问题

在文档里查找时，什么时候该按原文查找，什么时候该用模式？

## 简短回答

知道确切写法时，按原文查找，标点也照原样输入。只有要找多种结构相似的写法，而且当前工具明确支持正则表达式时，才需要切换模式。

正则表达式是指用来描述匹配条件的一套写法。比如在字符类中，方括号内列出的是同一位置可以接受的字符，并不意味着原文里应出现方括号。如果要找的就是带方括号的 `[draft]`，普通查找更直接。

## 推荐流程

1. 先新建一小段练习文本，把 `[draft]`、`draft`、`Ref-03`、`Ref-42` 和 `Ref-AA` 分别放在五行。再加上第六行 `Ref-031`，专门用来检查匹配会不会只覆盖一部分。
2. 用普通查找输入 `[draft]`。只有包含方括号的那一行符合原意；单独的 `draft` 不应该命中。如果高亮结果不同，看看正则选项是否还打开，也确认查找范围没有被限制在另一文件或选区里。
3. 如果工具支持正则，切换后试试 `Ref-[0-9][0-9]`。它可以找到 `Ref-03` 和 `Ref-42`，但找不到 `Ref-AA`。在 `Ref-031` 那一行观察高亮到哪里结束：前一部分符合条件，不代表整条编号只有两位。
4. 转到实际文档前，先决定什么样的结果才算有效。核对结果不需要点击替换。练习示例已经足够用来摸清设置，没必要把内部资料或私人文字粘贴到网页测试器里。

| 任务|适合的方式 |
| --- | --- |
| 查找包括标点在内的已知写法|普通查找 |
| 查找结构相同的一组编号|工具支持时用正则 |
| 排查不该出现的命中|检查高亮范围及周围文字 |

## 常见问题

### 没有正则选项怎么办？

把已知的写法分开查找。结果太多时，如果工具支持，可以调整大小写匹配或全字匹配，再看上下文。这些选项不会把普通查找变成模式匹配。

### 找不到就说明文件里没有吗？

不一定。先找一个肯定存在的词，或试试更短的原文片段，再检查查找范围和大小写设置。

## 结论

一般先按原文查找，需要覆盖多种写法时再换模式。在测试文本里留一个应该命中和一个不该命中的例子。
