# 资料发布日期和访问日期，笔记里怎么记？

今天打开一篇网页指南，看到页脚写的是去年。那个年份可能只是全站的版权声明，并不能说明这篇文章何时发布。需要看日期挨着什么内容、有没有标明用途，再决定记在哪一栏。

## 问题

资料发布日期和访问日期，笔记里怎么记？

## 简短回答

发布日期是指资料首次对外公开的日期。访问日期是指你实际查看这一页的日期。明确标为更新的日期应另记，不能拿来代替发布日期。

| 字段 | 填什么 |
| --- | --- |
| 发布日期 | 这篇文章明确标注的首次公开日期 |
| 更新日期 | 明确标为更新或修订的日期 |
| 访问日期 | 自己实际查看页面的日期 |

## 推荐流程

1. 先看文章标题和作者姓名附近，找直接属于这份资料的日期。把日期、原有标签和显示位置一起记下来，方便日后核对。
2. 保存实际查看的日期和页面链接。若页面有明确的版本号，也单独保存；版本能帮你找到当时看到的内容，却不能代替日期。
3. 如果只看到更新日期，就只填写更新栏。找不到原始发布日期时记为未知，不要用页脚的版权年份补空。
4. 如果下次访问时正文变了，保留旧笔记和旧访问日期。新内容另建一条记录，配上新的访问日期，方便比较两个版本。

例如，某个虚构页面于 2026-05-12 发布，你在 2026-06-03 查看，就把两个日期分别标明并记下网址。只有页脚的站点版权年份时，不要据此填写该页面的发布日期。整理参考文献时按指定的引用格式处理。

## 结论

分别记录资料上的日期和你阅读的日期。保存链接，保留能核实的标签；不确定的日期留空或标为未知。

## 常见问题

### 如果同一页面给出两个矛盾的日期怎么办？

先确认是否一个属于整站、另一个才属于文章。如果两处都像在说这篇文章，却没有足够依据判断，把两处标注连同位置都留下，并标为待核实。

### 参考文献一定要写访问日期吗？

不一定。先在笔记里保留，整理参考文献时再按指定格式处理。不同格式对没有发布日期或内容经常变化的网页有不同要求。
