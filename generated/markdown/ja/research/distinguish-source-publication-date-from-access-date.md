# 公開日と閲覧日、資料メモにはどちらを書く？

今日開いた解説ページの末尾に前年の数字があっても、それだけでは記事がいつ公開されたかは分かりません。日付が記事の見出しに付いているのか、サイト全体の権利表示なのかを最初に確かめます。

## 質問

公開日と閲覧日、資料メモにはどちらを書く？

## 短い回答

公開日とは、資料が一般に公開された日のことです。閲覧日は、実際にその資料を確認した日です。更新日と明記された日付は、初回の公開日とは別に記録します。

| 項目 | 記録する内容 |
| --- | --- |
| 公開日 | 記事に明示された公開の日付 |
| 更新日 | 更新と明記された日付 |
| 閲覧日 | 自分が実際にページを読んだ日 |

## 推奨ワークフロー

1. タイトルや著者名の周辺で、記事そのものに付いた日付を探します。数字だけでなく、日付のラベルと表示箇所を控えておくと後から照合できます。
2. 実際に読んだ日と、そのページを開いたアドレスをセットで記録します。版番号がある資料なら、別の欄に書いて日付と混ぜないようにします。
3. 更新日しか確認できないなら、その日付は更新欄に残します。元の公開日は不明とし、フッターの著作権年から推定しません。
4. 次に開いたときに本文が変わっていたら、前に読んだ内容のメモと閲覧日は上書きしません。新しい内容と閲覧日を別に記録すれば、どの版を読んだか分かります。

仮のページが 2026-05-12 に公開され、2026-06-03 に閲覧したなら、URL と一緒に両方を項目名付きで記録します。サイト下部の著作権年しか見当たらなければ、そのページの公開日は不明のままにしましょう。参考文献にまとめるときは指定された引用形式に従います。

## 結論

資料に表示された日付と、自分が読んだ日を混ぜないことが大切です。ページのURLと各日付のラベルがあれば、他の人も資料メモを確認できます。

## よくある質問

### 記事に二つの日付がある場合は？

両方とも記事の日時なのか、片方がサイト共通の表示なのかを確認します。記事上の二つの表示が矛盾する場合は、ラベルごと残して確認待ちとします。

### 参考文献にも閲覧日が必要ですか？

常に必要とは限りません。メモには残し、参考文献では指定された引用形式に従います。公開日の見つからない資料や頻繁に変わる資料は、形式によって扱いが異なります。
