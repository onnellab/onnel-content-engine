# 文書は文字どおりに検索する？それともパターンで検索する？

## 質問

文書内で文字列を探すとき、文字どおりの検索とパターン検索をどう使い分ければよいですか？

## 短い回答

表記が分かっていれば、記号も含めてそのまま検索します。共通の形式を持つ複数の文字列を探す場合は、使っているツールが正規表現に対応していることを確かめてから切り替えます。

正規表現とは、一致する文字列の条件を指定するための書き方です。たとえば文字クラスの角括弧は、その位置で許す文字の候補を表します。角括弧を含む `[draft]` そのものを探したいなら、通常検索から始めるほうが簡単です。

## 推奨ワークフロー

1. まず練習用に新しい文書を作り、`[draft]`、`draft`、`Ref-03`、`Ref-42`、`Ref-AA` を別々の行に書きます。六行目には、意図しない部分一致を見つけるために `Ref-031` を入れておきます。
2. 通常検索で `[draft]` を入力します。角括弧のない行に一致しないことを確かめます。予想と違ったら、正規表現の設定がオンのままではないか、別のファイルや選択範囲を検索していないかを確認してください。
3. 正規表現に対応している場合は、`Ref-[0-9][0-9]` を試します。これは `Ref-03` と `Ref-42` に一致し、`Ref-AA` には一致しません。`Ref-031` では強調表示がどこで終わるかを見ます。先頭の一部が一致しても、番号全体が二桁だとは限りません。
4. 実際の文書で検索する前に、どの範囲まで一致すれば目的を満たすかを決めます。結果を見るだけなら置換は不要です。試すときは架空の例を使い、社内文書や個人情報を外部サイトに貼り付けないでください。

| 目的|使う検索方法 |
| --- | --- |
| 記号も含めて既知の表記を探す|通常検索 |
| 同じ形式の番号をまとめて探す|対応ツールで正規表現 |
| 意図しない一致を調べる|強調表示の端と前後の文字を確認 |

## よくある質問

### 正規表現を使えない場合は？

分かっている表記を一つずつ検索します。結果が多すぎれば、ツールに大文字・小文字の区別や単語単位の設定があるかを確認してください。それらは通常検索を正規表現に切り替える設定ではありません。

### 何も見つからない場合は？

まず確実にある短い文字列で試します。検索対象や大文字・小文字の設定を確認してから、結果がないことを判断してください。

## 結論

最初は通常検索にし、複数の表記をまとめて探す必要があるときだけ切り替えます。一致する例と一致しない例を用意すると、設定の違いが分かりやすくなります。
