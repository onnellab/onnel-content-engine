# 文件裡要依原文搜尋，還是用模式搜尋？

## 問題

在文件裡找字時，什麼情況適合依原文搜尋，什麼情況才需要模式搜尋？

## 簡短回答

知道確切的字句，就連標點一起照原樣輸入。只有要找多種結構相近的寫法，而且目前的工具明確支援正規表示式時，才切換模式。

正規表示式是指用來描述符合條件的字串的一套寫法。像是字元類別中的方括弧，列出的是某個位置允許的字元，不代表結果必須出現方括弧。要找的是含方括弧的 `[draft]` 時，普通搜尋反而更直接。

## 建議流程

1. 先自己寫一小段測試文字，把 `[draft]`、`draft`、`Ref-03`、`Ref-42` 和 `Ref-AA` 分別放在五行。第六行加上 `Ref-031`，方便確認工具會不會只反白顯示其中一部分。
2. 用普通搜尋找 `[draft]`。只有含方括弧的那一行應該符合，沒有括弧的 `draft` 不應該被選中。如果反白結果不如預期，確認正規表示式選項是不是還開著，也檢查工具是否只搜尋另一份文件或選取範圍。
3. 如果工具支援正規表示式，就切換後輸入 `Ref-[0-9][0-9]`。它會找到 `Ref-03` 和 `Ref-42`，不會找到 `Ref-AA`。在 `Ref-031` 那一行，看看反白到哪裡結束。前段符合，並不代表整組編號只有兩位數。
4. 在真正的文件搜尋之前，先決定怎樣的結果才算有用。只是確認文字位置，不必使用取代功能。練習也可以只用自編文字，不必把內部資料或個人資訊貼到網路測試工具。

| --- | --- |

| 找到符合共同結構的編號|工具支援時用正規表示式 |
| 檢查不應出現的結果|檢查反白範圍及前後文字 |

## 常見問題

### 沒有正規表示式選項怎麼辦？

可以分開搜尋已知的寫法。結果太多時，如果工具支援，可以設定區分大小寫或全字相符，再看上下文。這些選項不會把普通搜尋改成模式搜尋。

### 沒有回傳結果，表示檔案裡沒有嗎？

不一定。先找一段確定存在的文字，或試試更短的原文片段，再檢查搜尋範圍與大小寫設定。

## 結論

一般先依原文搜尋，需要多種寫法才換模式。測試時記得放入一個應該符合的例子，以及一個不應該符合的例子。
