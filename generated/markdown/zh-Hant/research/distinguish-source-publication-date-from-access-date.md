# 資料的發布日期和查閱日期，筆記該怎麼記？

今天打開一份網頁指南，看到頁尾印著去年的年份。那可能只是整個網站的著作權聲明，並不等於這篇文章在同一年發布。把日期旁的文字和顯示位置一起看，才能判斷應該填在哪一欄。

## 問題

資料的發布日期和查閱日期，筆記該怎麼記？

## 簡短回答

發布日期是指資料首次對外公開的日期。查閱日期是指你實際查看該頁的日期。頁面若明確標示更新日期，就另外記錄，不用它取代發布日期。

| 欄位 | 記錄內容 |
| --- | --- |
| 發布日期 | 這篇文章明確標示的首次公開日期 |
| 更新日期 | 明確標示為更新或修訂的日期 |
| 查閱日期 | 自己實際查看頁面的日期 |

## 建議流程

1. 先在標題或作者署名附近找屬於這份資料的日期。記下原本的標示和顯示位置，不要只抄下日期本身。
2. 記下實際查閱日期，再儲存該頁網址。如果資料有版本編號，也可以另外記錄，讓自己日後知道讀的是哪個版本。
3. 若只有更新日期，就只填更新欄。查不到原始發布日期，記作未知即可，不要拿頁尾的著作權年份補上。
4. 如果之後重新查看時內文改了，保留原筆記及查閱日期。為新內容建一筆紀錄，填上新的查閱日期，日後便能分清楚當時看到的內容。

假設某個虛構網頁在 2026-05-12 發布，你在 2026-06-03 查閱，請將兩個日期分開標示，並附上網址。若只能找到頁尾的網站版權年份，不要據此推算該頁的發布日期。整理參考文獻時遵循指定的引用格式。

## 結論

把資料本身的日期和自己讀到資料的日期分開。保留網址與原有標示，沒有可靠依據的日期就註明未知。

## 常見問題

### 同一頁面出現兩個互相矛盾的日期怎麼辦？

先分辨其中是否有一個是全站共用的標示。兩個日期若都像是指該篇文章，卻無法確定哪個正確，就記下兩處標示及位置，註明待查。

### 參考文獻一定要加查閱日期嗎？

不一定。先保留在筆記裡，整理參考文獻時依指定格式決定是否列出。遇到無日期或經常變動的網頁，各種格式有不同做法。
