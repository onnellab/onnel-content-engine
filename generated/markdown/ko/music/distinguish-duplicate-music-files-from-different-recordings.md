# 중복 음악 파일과 서로 다른 녹음을 구분하는 방법

곡 제목이 같은 두 파일에도 서로 다른 연주가 담길 수 있어요. 반대로 파일명이 달라도 같은 파일의 복사본일 수 있죠. 음악 보관함을 정리하기 전에 무엇을 ‘중복’으로 볼지부터 구분해 보세요.

## 질문

서로 다른 녹음을 잘못 없애지 않고 음악 파일 두 개를 비교하려면 어떻게 해야 하나요?

## 짧은 답변

먼저 두 파일을 모두 보존하세요. 출처와 버전 표기를 확인하고 같은 구간의 소리를 비교해요. 파일 자체가 같은지와 녹음이 같은지를 구분하고, 제목·재생 시간·태그 하나만으로 판단하기 어려운 파일은 그대로 남겨 두세요.

![지우기 전에 비교해요](/blog-assets/ko/distinguish-duplicate-music-files-from-different-recordings/workflow-diagram.svg)

## 서로 다른 세 가지 비교

파일 동일성은 파일 전체의 바이트 내용이 같은 것을 의미합니다. 녹음 비교는 같은 연주와 믹스를 담고 있는지 살펴보는 과정입니다.

| 비교 대상 | 확인할 질문 | 이것만으로 알 수 없는 것 |
| --- | --- | --- |
| 파일 바이트 | 파일 전체의 내용이 동일한가요? | 다른 위치의 복사본이 필요한지 |
| 녹음 | 같은 연주와 믹스를 담고 있나요? | 인코딩이나 마스터링도 같은지 |
| 보관함 항목 | 같은 발매본의 같은 트랙 위치인가요? | 실제 파일이 동일한지 |

MusicBrainz는 녹음과 발매본의 트랙을 구분해요. 여기서는 그 용어 구분만 참고하며, 이를 파일 삭제 기준으로 삼지는 않아요. 데이터베이스 식별자도 잘못 연결됐다면 동일성을 보장하지 못해요.

## 권장 작업 순서

1. **원래 상태를 보존하세요.** 원본은 제자리에 두고 별도 메모에 비교 내용을 적어요. 나중에 정리하더라도 먼저 백업 파일이 실제로 열리는지 확인하세요. 이 비교에는 파일 이동·이름 변경·삭제가 필요하지 않아요.
2. **출처를 기록하세요.** 각 파일의 경로, 앨범이나 발매본, 트랙 위치, 버전 표기와 출처를 적어요. ‘라이브’나 ‘리믹스’라는 파일명은 단서일 뿐이에요. 확인된 근거와 구분하고, 모르는 정보는 미확인으로 남겨요.
3. **기술 정보를 과대해석하지 마세요.** 길이·크기·형식·비트레이트는 차이를 이해하는 단서이지 연주를 식별하는 증거는 아니에요. 파일 전체의 해시는 오디오 지문과 달라요. 태그나 인코딩만 달라도 해시가 달라질 수 있어요. SHA-256 같은 해시 알고리즘으로 계산한 값이 일치하면 바이트가 같다는 강한 근거지만, 복사본을 지워도 된다는 뜻은 아니에요.
4. **같은 구간을 편안한 음량으로 들어 보세요.** 도입부, 특징적인 중간 구간, 끝부분을 비교해요. 앞쪽 무음 길이가 다르면 실제로 같은 음악 구간을 맞춰요. 연주·편곡·믹스·페이드의 차이를 적되, 낯선 파일에 맞추려고 음량을 올리지 마세요. 음량 차이만으로 다른 연주라고 볼 수는 없어요.
5. **확인한 범위만 결론으로 적어요.** ‘바이트가 같은 파일’, ‘같은 녹음일 가능성이 있으나 파일 버전은 다름’, ‘다른 연주가 들림’처럼 구분해요. 근거와 미확인 사항도 남겨요. 몇 구간을 들은 것만으로 전체가 같다고 확정할 수는 없어요.

## 불확실하면 둘 다 남겨 두세요

가상의 ‘저녁 산책’ 파일 두 개 중 하나에만 시작 부분의 박수 소리가 있다고 해 봐요. 제목만으로는 구분할 수 없어요. 박수가 추가된 도입부인지, 다른 공연 전체가 담긴 것인지 확인해야 해요. 결론이 분명해질 때까지 두 파일과 확인할 질문을 함께 보존하세요.

## 주의할 점

이 비교는 음질 순위를 매기는 작업이 아니에요. 파일이 크거나 비트레이트가 높아도 원본 품질이 더 좋다는 보장은 없고, 변환으로 사라진 정보를 되살릴 수도 없어요. 같은 파일도 재생목록·발매본 폴더·백업에서 각각 필요할 수 있어요. 보존 여부는 연결 관계와 사용 가능한 백업을 확인한 뒤 별도로 판단하세요.

## 자주 묻는 질문

### 제목과 길이가 같으면 중복인가요?

아니에요. 검색 단서로는 유용하지만 파일이나 연주가 같다는 증거는 아니에요.

### 해시가 다르면 다른 녹음인가요?

아니에요. 파일 전체 해시는 오디오 외의 바이트나 인코딩이 바뀌어도 달라져요. 차이의 원인까지 설명하지는 못해요.

### 차이를 못 듣겠으면 하나를 지워도 되나요?

그 이유만으로 판단하지 마세요. 동일성이나 용도가 불확실하면 둘 다 남기고 비교한 범위를 기록하세요.
