# 텍스트를 글자 그대로 검색할까, 패턴으로 찾을까?

## 질문

문서에서 글자 그대로 검색할 때와 패턴 검색을 쓸 때를 어떻게 구분하나요?

## 짧은 답변

찾는 문구가 어떻게 적혔는지 알면 글자 그대로 검색하세요. 일정한 형태를 공유하는 여러 항목을 찾고, 도구가 정규식을 지원할 때 패턴 검색으로 바꾸세요.

정규식은 어떤 문자열이 검색에 걸리는지 정하는 규칙입니다. 예를 들어 정규식의 대괄호로 문자를 묶으면 그 자리에서 허용할 문자 후보를 지정할 수 있어요. 대괄호까지 포함한 `[draft]`를 찾는다면 오히려 일반 검색이 더 알맞아요.

## 권장 워크플로

1. 가상의 짧은 연습 문서를 만드세요. `[draft]`, `draft`, `Ref-03`, `Ref-42`, `Ref-AA`를 줄마다 하나씩 적어요. 여섯 번째 줄에는 `Ref-031`을 적어 검색 결과에서 일부만 강조되는 경우도 살펴보세요.
2. 일반 검색에 `[draft]`를 입력하세요. 대괄호 없는 `draft` 줄은 이 검색에 걸리지 않아야 해요. 예상과 다르게 표시되면 정규식 옵션이 켜져 있는지, 찾으려는 파일이나 선택 영역을 검색 중인지 확인하세요.
3. 도구에서 지원한다면 정규식 모드에서 `Ref-[0-9][0-9]`를 시험하세요. `Ref-03`과 `Ref-42`는 찾고 `Ref-AA`는 건너뛰어요. `Ref-031`에서는 어디까지 강조됐는지 확인하세요. 앞부분이 맞는다고 전체 번호가 반드시 두 자리인 건 아니에요.
4. 실제 문서로 넘어가기 전에 어떤 결과가 맞는지 정하세요. 검색 결과 확인에는 바꾸기 기능이 필요 없어요. 자료가 외부로 나가면 안 된다면 실습 예시만 써도 되고, 실제 문구를 온라인 검사 도구에 붙일 필요는 없어요.

## 자주 묻는 질문

### 정규식 옵션이 없어도 찾을 수 있나요?

네. 아는 표기를 하나씩 나눠서 검색하세요. 결과가 너무 많다면, 도구에서 지원하는 경우 대소문자 구분이나 단어 단위 검색을 사용한 뒤 앞뒤 문맥을 확인하세요. 이런 옵션이 일반 검색을 정규식으로 바꾸지는 않아요.

### 검색 결과가 없으면 문서에 없는 건가요?

먼저 분명히 있는 예시나 더 짧은 문자열로 검색해 보세요. 검색 범위와 대소문자 옵션을 확인한 뒤에 결과를 해석하세요.
