# 긴 일반 텍스트 문서에서 필요한 부분을 쉽게 찾는 방법

## 질문
긴 TXT 문서에서 읽던 곳이나 필요한 단락을 어떻게 다시 찾을 수 있을까요?

## 짧은 답
원본을 보존하고 읽기 전용으로 볼지 별도 작업본을 쓸지 먼저 정하세요. 기존 제목을 별도 메모에 정리하고, 특징적인 문구를 검색해 문맥을 확인하세요. 외부 위치 메모로 경로를 남긴 뒤 같은 버전을 다시 열어 확인하세요.

## 스크롤 위치만으로는 부족한 이유
화면에서 보이는 위치는 문서의 고정된 주소가 아닙니다. 창 너비, 글꼴 크기, 줄바꿈 설정이 달라지면 같은 문장도 다른 화면에 나타날 수 있습니다. 화면상 몇 번째 줄이었는지만 기억하기보다 검색할 문구와 주변 문맥을 함께 남기는 편이 낫습니다.

일반 텍스트의 제목도 기본적으로는 문자입니다. 특정 기호가 있다고 모든 뷰어가 목차나 이동 버튼을 만들어 주지는 않습니다. 이 글은 본문에 제목을 추가하는 편집 방법이 아니라, 기존 구조를 바탕으로 다시 찾아갈 경로를 만드는 방법입니다.

외부 위치 기록은 원본을 수정하지 않고 파일 버전과 다시 찾을 단서를 별도 메모에 남기는 방법입니다.

| 위치 단서 | 쓰임 | 확인할 한계 |
| --- | --- | --- |
| 기존 제목 | 구간 구분 | 반복되는 제목은 문맥 필요 |
| 특징적인 문구 | 단락 검색 | 버전이 바뀌면 문구도 바뀔 수 있음 |
| 줄 번호 | 위치 정보 보완 | 화면 줄바꿈과 파일 수정의 영향 확인 |

## 다섯 단계 작업 방법

1. **원본을 보존하고 작업 방식을 정하세요** 읽기만 할 문서는 가능하면 뷰어의 읽기 전용 기능을 사용하세요. 편집이 필요한 경우에도 원본과 구별되는 작업본을 먼저 준비하세요. 원본 기록, 증거 자료, 로그에는 탐색용 표식을 삽입하지 마세요. 파일을 열거나 가져올 때 원본을 직접 다루는지, 별도 복사본을 만드는지도 확인하세요. 탐색을 위해 형식이나 인코딩을 무작정 바꿀 필요는 없습니다.

2. **기존 구조를 별도 메모에 정리하세요** 문서에 이미 있는 의미 있는 제목과 구간 이름을 골라 짧은 목록을 만드세요. 제목이 없다면 구간을 식별할 수 있는 기존 문구를 적으세요. 본문은 바꾸지 않고, 외부 메모에 파일 이름과 확인한 버전 또는 날짜를 함께 남기세요. 모든 단락을 목록에 넣기보다 다시 찾을 가능성이 높은 부분부터 기록하면 됩니다.

3. **특징적인 문구를 검색하고 문맥을 확인하세요** 선택한 문구를 그대로 검색해 보세요. 자주 나오는 일반적인 단어보다 후보를 좁힐 수 있는 짧은 문구가 유용합니다. 첫 결과만 믿지 말고 앞뒤 문장과 상위 제목을 확인하세요. 같은 문구가 반복되면 검색어를 구체화하거나 결과를 구분할 문맥을 추가하세요. 대소문자나 단어 단위 검색 등 옵션은 뷰어마다 다르므로 실제 결과로 확인해야 합니다.

4. **외부 위치 메모로 경로를 남기세요** 외부 메모에 파일 버전, 제목, 검색 문구, 주변 문맥과 돌아올 이유를 적으세요. 줄 번호는 보조 정보일 뿐입니다. 화면상 자동 줄바꿈과 파일의 실제 줄바꿈은 다르며, 파일 수정으로 번호가 달라질 수도 있습니다.

5. **같은 버전을 다시 열어 확인하세요** 파일을 닫고 같은 버전을 다시 연 뒤, 저장한 경로로 목표 단락을 찾으세요. 결과가 여러 개라면 메모에 구분 정보를 보완하세요. 버전이 바뀌었다면 이전 위치를 그대로 신뢰하지 말고 문맥을 다시 확인하세요. 다른 사람에게 경로를 전달하기 전에도 파일과 버전이 일치하는지 점검하세요.

## 이 방법의 한계
위치 메모는 탐색을 돕지만 내용의 정확성이나 파일 열기 속도를 보장하지는 않습니다. 글자 깨짐이나 열기 실패는 별도로 확인해야 합니다. 메모를 공유할 때는 필요한 최소한의 문구만 옮기고 민감한 내용을 불필요하게 복사하지 마세요.

## 자주 묻는 질문

### 모든 제목을 기록해야 하나요?
아니요. 다시 찾아갈 가능성이 높은 구간부터 기록하세요. 목록이 너무 길어지면 별도 메모도 탐색하기 어려워집니다.

### 줄 번호만 기록해도 되나요?
보조 정보로는 유용하지만 수정과 표시 방식의 영향을 확인해야 합니다. 특징적인 문구와 제목을 함께 기록하세요.

### 파일 버전이 바뀌어도 같은 메모를 쓸 수 있나요?
제목이나 문구가 바뀌거나 이동할 수 있습니다. 새 버전에서 검색 결과와 문맥을 다시 확인하고, 메모가 가리키는 버전을 갱신하세요.

## 결론
스크롤 위치보다 다시 검색할 수 있는 표식과 문맥을 남기세요. 원본을 보존하고 같은 버전을 다시 열어 경로를 시험하는 것이 핵심입니다.
