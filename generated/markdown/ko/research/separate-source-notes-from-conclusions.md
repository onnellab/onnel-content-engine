# 출처 메모와 자신의 결론을 구분하는 방법

## 질문

출처에 담긴 내용과 자신이 내린 결론을 어떻게 구분하나요?

## 핵심 답변

모든 인용문과 바꿔 쓴 내용에 출처와 해당 부분의 정확한 위치를 남기세요. 자신의 해석은 따로 적고, 출처에서 다루는 범위와 한계를 유지하세요. 더 강한 결론을 내리기 전에 무엇을 확인해야 하는지도 기록하세요. 다른 사람이 말한 내용과 자신의 추론이 구분되도록 하는 것이 핵심입니다.

출처 이력은 메모의 내용이 어디에서 왔는지 남긴 기록을 뜻합니다. 추론은 그 내용을 바탕으로 자신이 내린 결론을 말합니다.

독서 기록은 무엇을 읽었는지 남깁니다. 여기서 소개하는 절차는 그보다 좁은 문제를 다룹니다. 자신의 추론을 출처에 적힌 내용으로 취급하지 않으면서, 각 주장이 어디에서 나왔는지 추적하는 방법입니다.

## 구분해서 적을 세 가지 항목

출처의 직접 인용문이나 바꿔 쓴 내용, 자신의 해석, 다음에 확인할 내용을 각각 별도의 항목에 적으세요. 어떤 메모 도구를 쓰든 열을 나누거나 항목 이름을 붙여 기록할 수 있습니다.

아직 입증되지 않은 해석도 유용할 수 있습니다. 메모를 글의 개요로 옮기거나 다른 사람과 공유할 때도 그 해석이 어떤 상태인지 드러나게 하세요.

## 가상의 예시

아래 메모와 참여자, 결과는 이 방법을 설명하기 위해 만든 가상의 내용이며, 실제 연구 결과가 아닙니다. 두 가지 메모 양식을 비교한 가상의 예비 조사 메모를 검토한다고 생각해 보세요.

| 출처 메모와 해당 위치 | 나의 해석 | 다음에 확인할 내용 |
| --- | --- | --- |
| 직접 인용: “참여자 6명 중 4명이 세션 종료 시 양식 B를 선택했다.” 메모 A, v1, §2. | 이 집단을 대상으로 B를 더 살펴볼 가치는 있을 수 있다. 이것이 학습 효과가 더 좋다는 근거는 아니다. | 참여자들은 어떤 이유를 들었는가? |
| 바꿔 쓰기: 참여자들은 조용한 방에서 각자 작업했다. 메모 A, v1, §1. | 이 관찰을 협업 상황으로 확대해 해석할 수는 없다. | 공동 작업에서도 같은 질문이 중요할까? |
| 바꿔 쓰기: 일정 시간이 지난 뒤 기억을 확인하는 과제는 포함되지 않았다. 메모 A, v1, §3. | 나중에 얼마나 기억하는지는 아직 알 수 없다. | 기억 유지가 우리의 질문이라면, 어떤 근거가 답을 줄 수 있을까? |

“양식 B는 학습 효과를 높인다”라는 결론은 이 가상의 메모가 뒷받침하는 범위를 넘어섭니다. 선호, 작업 환경, 측정하지 않은 결과를 합쳐 더 강한 주장으로 만들지 마세요.

## 권장 워크플로

1. 출처와 해당 부분의 위치 기록하기: 제목을 적고, 확인할 수 있다면 저자나 기관도 기록하세요. 링크나 파일 식별 정보를 함께 남기고, 해당 내용을 찾는 데 필요한 페이지, 절, 문단, 타임스탬프를 추가하세요. 내용이 바뀔 수 있는 자료는 버전이나 열람 날짜도 적으세요. 제목만으로는 자신이 사용한 부분을 찾기 어려울 수 있습니다.

2. 직접 인용인지 바꿔 쓴 내용인지 표시하기: 직접 인용문은 정확하게 옮기고 따옴표로 표시하세요. 바꿔 쓴 내용은 그렇게 표시한 뒤, 따옴표 없이 자신의 말로 적으세요. “이 표본에서”, “가능성이 있다”처럼 범위나 확실성을 제한하는 표현도 유지하세요. 문구가 모호하다면 임의로 의미를 정하지 말고 해당 부분을 그대로 보관하세요.

3. 자신의 해석은 따로 쓰기: “나의 해석”이라는 항목을 만드세요. 그 내용에서 무엇을 도출할 수 있다고 생각하는지, 왜 그렇게 생각하는지 적으세요. 여러 출처를 연결한다면 각 출처의 해당 위치를 남기세요. 출처가 하지 않은 추가 주장까지 포함된 문단에 인용 표시 하나만 붙이지 마세요.

4. 맥락을 보존하고 다음 확인 사항 정하기: 참여자, 환경, 기간, 정의, 제외 조건 등 관련 정보는 출처에서 제공한 경우에만 기록하세요. 없는 정보는 알 수 없다고 표시하세요. 빈 부분을 추정으로 채우는 대신 구체적인 질문으로 바꾸세요. 판단에 영향을 주는 질문부터 우선 확인하면 됩니다. 모든 빈틈에 새로운 조사가 필요한 것은 아닙니다.

5. 간단한 이력을 남기며 수정하기: 옮겨 적는 과정의 오류를 발견하거나 추론을 바꾼 경우, 작업 중인 메모를 수정하세요. 무엇을 왜 바꿨고 어느 부분을 읽고 수정했는지 날짜와 함께 짧게 남기세요. 이전 결론에는 새 결론으로 대체되었다고 표시해 현재 입장으로 오해되지 않게 하세요.

## 이 방법의 한계

출처를 명확히 기록해도 자료의 정확성이나 추론의 타당성이 입증되는 것은 아닙니다. 관련성, 연구 방법, 상충하는 자료는 별도로 검토해야 합니다. 메모나 공유할 초안에 불필요한 개인정보나 기밀 정보를 옮겨 적지 마세요.

## 결론

메모를 다시 활용하기 전에 누구의 말이 담겨 있는지, 그 내용이 어디에서 왔는지, 어떤 결론이 자신의 것인지 확인하세요.

## 자주 묻는 질문

### 모든 출처를 직접 인용해야 하나요?

아니요. 적절한 경우에는 의미와 해당 위치 정보를 유지하면서 자신의 말로 바꿔 쓸 수 있습니다. 정확한 표현 자체가 중요할 때 직접 인용하세요.

### 여러 출처를 종합해 하나의 결론을 내려도 되나요?

네. 각 출처가 어느 부분을 뒷받침하는지 밝히고, 종합한 해석은 자신의 것이라고 표시하세요. 출처 사이의 견해 차이도 드러나게 남기세요.

### 원문의 해당 부분을 찾을 수 없다면 어떻게 하나요?

미확인 메모로 표시하세요. 기억나는 문구를 직접 인용문처럼 제시하지 마세요. 그 내용에 의존하기 전에 원문의 해당 부분을 찾으세요.
