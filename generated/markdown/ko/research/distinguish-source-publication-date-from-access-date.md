# 자료의 게시일과 열람일, 메모에 어떻게 적을까?

오늘 확인한 안내문 하단에 작년 날짜가 보여도 그 숫자가 글의 게시 연도인지는 알 수 없어요. 날짜가 적힌 위치와 옆에 붙은 이름을 확인하면, 사이트 전체의 표기와 이 글에 관한 표기를 구분하기 쉬워요.

## 질문

자료의 게시일과 열람일, 메모에 어떻게 적을까?

## 짧은 답변

게시일은 자료가 공개된 날짜를 나타내요. 열람일은 내가 자료를 직접 확인한 날짜를 뜻해요. 자료가 수정된 날은 별도로 표시된 경우에만 수정일로 적어요.

| 날짜 항목 | 적을 내용 |
| --- | --- |
| 게시일 | 해당 글에 표시된 최초 공개 날짜 |
| 수정일 | 별도로 표시된 업데이트 날짜 |
| 열람일 | 직접 페이지를 확인한 날짜 |

## 권장 워크플로

1. 제목과 작성자 이름 주변부터 보세요. 이 자료에 직접 붙은 날짜가 있다면 날짜와 항목 이름, 표시 위치를 함께 기록하세요.
2. 실제로 자료를 확인한 날과 페이지 주소를 적으세요. 문서에 판 번호나 버전이 보이면 날짜와 다른 칸에 적어 두세요.
3. 수정일만 확인된다면 그 날짜를 수정일로만 남겨요. 게시일을 모른다면 미상으로 두고, 사이트 하단의 저작권 연도로 빈칸을 대체하지 않아요.
4. 날짜를 다시 확인하러 갔을 때 본문이 바뀌었다면, 이전 메모와 열람일은 보존해요. 새로 읽은 내용과 날짜는 새 기록에 묶어 두는 편이 비교하기 쉬워요.

가상의 페이지가 2026-05-12에 게시됐고 2026-06-03에 읽었다면, 두 날짜에 각각 이름을 붙여 URL과 함께 남기세요. 하단의 사이트 저작권 연도만으로 페이지 게시일을 추정하지 마세요. 참고문헌으로 옮길 때는 요구되는 인용 양식을 따르세요.

## 결론

날짜마다 이름표를 붙이는 것이 핵심이에요. 자료 주소와 실제 열람일을 남기고, 확인할 수 있는 자료의 게시일과 수정일만 따로 적어 두세요.

## 자주 묻는 질문

### 서로 다른 날짜가 둘 다 게시일처럼 보이면요?

하나는 사이트 전체에 관한 날짜인지 살펴보세요. 둘 다 해당 글에 붙어 있지만 설명이 모호하다면, 두 날짜를 위치와 함께 적고 확인이 필요하다고 표시해요.

### 참고문헌에도 열람일을 꼭 넣어야 하나요?

항상 그런 건 아니에요. 메모에는 보존하되 최종 참고문헌에는 요구받은 인용 양식을 따르세요. 날짜가 없거나 내용이 자주 바뀌는 자료의 처리 방식도 양식마다 달라요.
